* I spotted one issue in the new set_instance helper. The guard is trying to ensure the caller passes a Util::Config object, but it does that by calling $new_instance->isa(__PACKAGE__). If a caller accidentally hands us an unblessed reference (for example a plain hashref coming from a test double), Perl throws Can't call method "isa" on unblessed reference before we ever reach the croak, so we still crash with a confusing message.
Could we switch the guard to use something like Scalar::Util::blessed($new_instance) (or UNIVERSAL::isa) before we invoke isa, so we can reliably emit the custom error message?
